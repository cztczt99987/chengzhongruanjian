| `backups\` | 自动/手动备份文件（backup_日期_时间.db） | 备份恢复测试 |

## 0.4 config.json 关键配置项（测试中会临时修改的）

程序运行时读取 exe 目录下 `config.json`，**修改后需重启程序生效**（数据源切换菜单除外）。

| 配置项 | 默认值 | 含义 | 测试用途 |
|---|---|---|---|
| DataSourceMode | Simulator | Simuator=模拟数据源 / Serial=串口 | 第 2 章数据源切换 |
| Unit | t | 重量显示单位（t=吨 / kg=千克） | 全程影响显示与录入 |
| StableCount / StableToleranceKg | 3 / 5 | 连续 3 次采样差值 <5kg 判定稳定 | 稳定判定 |
| MaxCapacityKg | 100000 | 最大量程 100 吨，超过判超载 | T48 超载测试时临时改小 |
| UnfinishedWarnHours | 24 | 一次磅超时未配对标红的小时数 | T21 标红测试时临时改小 |
| ConfirmBeforeSave | true | 保存前是否二次确认 | T17 关闭确认测试 |
| CameraEnabled / CameraCount | true / 4 | 视频监控开关与路数 | 第 5 章 |
| PortName / BaudRate 等 | COM9 / 9600 / 8 / None / One | 串口参数 | T12 串口测试 |

> **注意**：当前 config.json 文件里只写出了上表中的部分字段（DataSourceMode、串口参数、稳定参数、MaxCapacityKg、Unit、ScaleNo），其余字段（如 ConfirmBeforeSave、UnfinishedWarnHours、CameraEnabled）走程序内置默认值。**测试中若要修改的字段在文件里不存在，请按 JSON 格式手动添加一行**（加在最后一个字段后面时，记得给上一行末尾补逗号）。另外：使用过一次"数据源"菜单切换后，程序会把全部字段写全，之后就能直接改了。

## 0.5 模拟数据源的运动规律（重要，影响多个测试）

默认数据源为"模拟数据源"，它模拟一辆车过磅的全过程，节奏如下：

1. **空磅**：重量显示 `0 t`，持续随机几秒到几十秒；
2. **上磅**：随机"驶入"一辆 20~60 吨的车，重量在几秒内逐步上升；
3. **稳定**：到目标重量后轻微抖动（±3kg），**稳定期约 8 秒**，此时状态显示 `● 稳定`（绿色）；
4. **离磅**：重量快速回落到 0，回到空磅状态，然后循环下一辆。

> 因此：**想"趁稳定期保存"，要提前把车号等信息填好，看到 `● 稳定` 后立即点保存**。错过了稳定期也没关系——用"补录重量"功能手工输数即可（见第 3、4 章）。

## 0.6 测试数据准备建议

为了让查询、报表、留痕等测试有数据可查，建议先按第 3、4 章完成 **2~3 车完整的两次称重**（其中至少 1 车用补录方式），并给 1 条记录做一次修改、1 条记录做作废，再进入后续章节。
