# 过磅单格式设计功能模块 — 实施计划

## Context（背景）

现有系统已有基础磅单模板能力：`PrintTemplate` 模型（文本/线条/矩形/图片元素，毫米坐标，JSON 存于 `templates/`）、`TemplateDesignerForm` 基础设计器（拖拽/手柄/属性网格/占位符插入）、`TemplateTicketRenderer` 共用渲染、打印与打印设置。

本次需求在此基础上补齐完整功能模块：
- **模板管理**：≥5 种内置行业模板（物流/仓储/矿山等）、分类+搜索+预览+应用启用、重命名/删除/复制
- **设计增强**：表格、签名区、二维码（QRCoder）、条形码（Code39 手绘）四类新元素；文字/线条/矩形颜色；占位符格式后缀（`{毛重:F1}`、`{一次磅时间:yyyy-MM-dd}`）
- **撤销/重做**（快照式 Ctrl+Z/Y）、工具箱拖放添加、窗体内帮助说明
- **输出**：PDF 导出（Microsoft Print to PDF 虚拟打印机）、批量打印 + 批量导出 PDF（记录查询多选）

已与用户确认的决策：QRCoder 库生成二维码；Microsoft Print to PDF 导出；第 6 条"浏览器兼容"按桌面应用理解（DPI 适配 + GDI 渲染保证跨打印机一致），不做 Web 界面；批量 = 批量打印 + 批量 PDF。

基线状态：工作区干净（最新提交 `3176bd2`），占位符已适配"发货单位/收货单位"拆分，`dotnet build` 通过。

原则：在现有类上扩展，不重写；`PoundTicketPrinter.RenderTo / Print / PrintPreview` 等既有公共 API 签名不动（`UiDpiVerify` 工具依赖 `RenderTo`）。

## Step 2：模板模型与渲染扩展（核心数据结构）

**修改 `src/CZRWeighSystem/Report/PrintTemplate.cs`**
- `PrintTemplate` 新增 `Category`（默认"通用"）
- `Expand` 支持格式后缀：正则改为 `\{([^{}:]+)(?::([^{}]+))?\}`；新增 `BuildRawValues()` 返回类型化原值表（重量→double?、时间→DateTime?、其余 string）；带格式时按 raw 值 `ToString(fmt)`，格式非法回退默认字符串值；保留旧签名兼容
- 元素模型：`TextElement.ForeColor`、`LineElement.Color`、`RectElement.Color` + `FillColor`（null 不填充），颜色用 `#RRGGBB` 字符串（PropertyGrid 文本编辑，简单优先）
- 新增元素（注册 `JsonDerivedType`，均有默认值保证旧 JSON 兼容）：
  - `TableElement`：`Columns: List<TableColumn>`（表头/文本占位符/宽/对齐）+ `RowH`
  - `SignatureElement`：`Labels`（如 司磅员/客户签字）均分宽度画"标签：____"
  - `QRCodeElement`：`Content` 支持 `{占位符}`
  - `BarcodeElement`：`Content` 支持 `{占位符}` + `ShowText`
- 新增 `CreateBuiltins()`（5 种内置模板）+ `EnsureBuiltinsOnDisk()`（仅写缺失文件，文件名 `内置_名称.json`）

**新建 `src/CZRWeighSystem/Report/Code39.cs`**（纯逻辑可测）
- `IsValid` / `Encode`（自动加 `*` 起止符，返回条/空交替序列，宽窄 2:1）/ `TotalUnits`

**修改 `src/CZRWeighSystem/Report/TemplateTicketRenderer.cs`**
- switch 增加 4 个新元素绘制：表格（外框+表头线+列分隔+逐格对齐绘制）、签名区、二维码（QRCoder 生成位图按内容缓存 + NearestNeighbor 缩放）、条码（窄条宽 = 元素宽/TotalUnits，逐段填充）
- 新增 `ParseColor`（`#RRGGBB` / 颜色名，失败回退黑色）；文本/线条/矩形改用解析后的颜色

**修改 `src/CZRWeighSystem/CZRWeighSystem.csproj`**：加 `QRCoder 1.8.0`

追加测试：Expand 格式后缀各路径、Code39 编码不变量（每字符 9 单元恰 3 宽、TotalUnits 一致）、内置模板 5 个且元素类型 JSON 往返保留。

验证：build + test 全绿。Commit：`磅单模板新增表格/签名/二维码/条码元素、颜色与{字段:格式}占位符，内置5种行业模板`

## 内置 5 种模板（CreateBuiltins）

| 模板 | 分类/纸张 | 构成要点 |
|---|---|---|
| 通用A4磅单 | 通用/A4 | 现 CreateDefault 结构 + 二维码({流水号})，约 20 元素 |
| 物流运输磅单 | 物流/A4 | 二维码右上、表格(车号/货物/规格/批次)、条码、签名区(司磅员/司机/客户) |
| 仓储出入库磅单 | 仓储/A4 | 表格 6 列(车号/货物/规格/毛皮净)、备注区、签名区(仓管员/司机/库管)、条码 |
| 矿山销售磅单 | 矿山/A4 | 矿点、净重超大字({净重:F1} 红色)、表格(发货/收货/批次)、条码、签名区 |
| 针打连单 | 物流/241×140 | 紧凑两列、条码左上、表格 2 列(发货/收货)、签名区 |
